## Strongest remaining weakness

The novelty moat is conditional. Known work already supplies Heston PI operators, derivative supervision, shape constraints and warnings about Greek instability. The rigorous elementary theory planned here is mostly classical. A defensible paper therefore needs a controlled, useful result about joint reliability or a non-obvious failure frontier, beyond a positive penalty ablation. Neither exists yet. A second risk is whether Gamma can be numerically certified across severe short-time/low-variance regimes at acceptable cost.

## Proceed / stop decision

GO for Phase1B reference implementation and its validation only. NO-GO for new model training, large framework or manuscript writing until the reference gate passes and the study's novelty/feasibility is reviewed. Do not promise that this design alone makes the project publication-ready. Main-paper scope deliberately excludes real data and theoretical global no-arbitrage guarantees.

## Exact Phase1B recommendation

1. Create fresh `reference/` modules for a stable probability representation, independent COS/Riccati-CF route, shared unit/input schema only, explicit special limits and numerical uncertainty/status outputs. Never import the old Heston solver or labels.
2. Add reference-only unit and convergence tests: CF convention/moments, zero-time payoff, sigma-zero integrated variance, parity/homogeneity, A/B convergence, analytic/COS/FD Greeks, numerical-error amplification and all named regime cases.
3. Pin the actual Python/dependency environment and optional QuantLib source/version; record temporal conventions and any unavailable external APIs. Use local small smoke checks first; create a user-run Colab validation script for larger grids if needed, with no neural training.
4. Save every refinement, stencil, failure and external comparison to a versioned `reference_validation/` directory; produce `REFERENCE_CERTIFICATE.md` and machine-readable report that distinguishes price and Greek acceptance and numerical versus formal certification.
5. Review that evidence against [REFERENCE_ENGINE_SPEC.md](REFERENCE_ENGINE_SPEC.md). Stop on unresolved core failures; explicitly version any domain change before data generation.
6. Only after that review request a separate Phase1C authorization for immutable dataset generation and a small development pilot. Full model training remains user-run COLAB-HEAVY in a later phase.

No step above has been implemented or executed in Phase1A. Old files and Phase0 outputs remain preserved.
