# Phase 1B protocol v1.1 (frozen before certification sweep)

Domain v1 and all acceptance budgets in `design/REFERENCE_ENGINE_SPEC.md` are retained. Grid v1.1 replaces 256 random parameter blocks with scrambled Sobol blocks, seed 4101, and uses a separate state Sobol sequence seed 4102. The 1680 deterministic points and 64 challenge points remain; total 5840. This is a coverage change requested in Phase1B, not a tolerance change. No failures are filtered by Feller ratio.

Local execution is a 25-point diagnostic slice, not the specified 256-point smoke gate. Full iterative coverage, external checks, and the 256-point FD requirement are prepared for user-run Colab. Missing mandatory coverage yields gate FAIL, even if local tests pass. No conditional certified subdomain is inferred from a small sample.

Normalized budgets: price `1e-8+1e-6*max(abs(cA),abs(cB))`; Delta `2e-6+1e-5*max(abs(DA),abs(DB))`; KGamma and Vv/K `2e-5+1e-4*max(abs(A),abs(B))`. Near-zero relative price error is undefined below reference magnitude 1e-5, stored as NaN. Other relative Greek gaps use the maximum route magnitude; exact zero denominators are NaN. Challenge points receive the same budgets. No relaxation.

For each evaluated row, A uses cutoff 64,128,256,512,1024,2048, tolerance 1e-9,1e-11,1e-13 at U=2048, and panels 4,8,16 at the finest tolerance. B uses N=64,128,256,512,1024,2048,4096 independently at L=8,12,16,24,32. Final two differences in each axis, for every output, must be <= one quarter of the corresponding budget. Quadrature reported error excludes the integration tail. Maximum reference differences are diagnostic metadata, not rigorous error bounds. Any solver exception or integration failure is retained and fails the row.

A is float64 only. Its precision option rejects unsupported precision explicitly. Failure to converge is escalated to future independently checked higher precision, never silently switched or clipped. B uses compensated real summation. Both return unclipped values; the exact terminal payoff is a mathematical boundary condition, not clipping a numerical price.

FD uses the predeclared six relative steps and five-point physical-S stencils; v uses centered stencils or the fourth-order right stencil (-25,48,-36,16,-3)/(12h). For B the base interval is held fixed over every stencil. Store each stencil value. Acceptance requires two final FD increments and analytic/FD discrepancy <= Greek budget/4. Conservative amplification of the *diagnostic* cross-route price gap plus A quadrature estimate is recorded separately; it is not a proven bound. A failed amplification budget leaves the FD evidence unresolved. Last-step agreement does not remove missing higher-precision evidence.

Financial sanity budgets use price/Greek tolerances and homogeneity identities `V_K=(V-S Delta)/K`, `V_KK=(S/K)^2 Gamma`; also independently check strike FD on representative points. Test homogeneity at K=50,100,200. CF checks: zero, moment, conjugation, dense-frequency continuity, parameter perturbations and >=32 direct complex Riccati ODE comparisons. Exact zero/first-moment CF values are imposed identities and therefore also compared with the unforced ODE solution.

Third-party adapter is optional QuantLib 1.41, analytic plus FD refinements. Match actual/365 times exactly: only maturities with integral tau*365 are accepted. Additional external-only cases use integer-day maturities. Absence/version mismatch/unresolved external refinement is recorded; an ODE CF check alone is not third-party price/PDE validation.

Classification is conservative: convergence failure flags the failing numerical axis; exceptions and unexplained cross-route gaps are `unknown`. v=0 and short maturity are context flags, not proof of a causal pathology. Raw failed values remain in results and failures. No interpolation of failed rows in figures. Summary finite statistics always show valid/missing counts and failed-point locations. Log plots use a declared display floor only, without modifying raw values.

PASS requires full Domain v1 mandatory cases, refinements, sanity, CF/ODE, 256 FD checks, deterministic rerun/serialization checks and reviewed external conventions/evidence. The automated runner never grants PASS on its own: successful full checks leave external review INDETERMINATE until actual external artifacts are accepted. Domain revisions require a new protocol and a documented failure map before Phase1C. No neural dataset generation or training is part of this module.
